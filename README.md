# تنبيه ورد المراجعة اليومي

بيبعت رسالة كل يوم على جروب تيليجرام فيها ورد المراجعة (من صفحة كذا لصفحة كذا مع أسماء السور). بيشتغل مجانًا على GitHub Actions، من غير سيرفر ومن غير جهازك يكون شغال.

الحاجة الوحيدة اللي هتدخلها بنفسك: **مفتاح البوت (API Key)**.

## التشغيل خطوة بخطوة (10 دقايق)

### 1) اعمل البوت وخد المفتاح
1. افتح تيليجرام وابحث عن `@BotFather`.
2. ابعت `/newbot`، اكتب اسم للبوت، وبعدها اسم مستخدم لازم ينتهي بـ `bot`.
3. هيرد عليك بمفتاح شكله `123456789:AAH...`. انسخه، ده المفتاح.

### 2) ضيف البوت للجروب
- افتح الجروب، اختار Add member، وضيف البوت.
- ابعت أي رسالة في الجروب (مثلاً "السلام عليكم").
- مش لازم تعمل البوت مشرف.

### 3) ارفع المشروع على GitHub
1. اعمل حساب على github.com لو معندكش، واضغط **New repository**.
2. اكتب أي اسم (مثلاً `quran-reminder`)، واختار **Public** (شرح السبب تحت)، واضغط Create.
3. فك ضغط المجلد ده، وفي صفحة المستودع اضغط **Add file ← Upload files**، واسحب كل الملفات اللي جوه المجلد، واضغط Commit.
4. تأكد إن فيه مجلد `.github` في المستودع. لو مجلد `.github` مظهرش لأن جهازك بيخفي الملفات اللي بتبدأ بنقطة: اضغط **Add file ← Create new file**، اكتب في خانة الاسم `.github/workflows/remind.yml`، والصق جواه محتوى ملف `remind.yml`، واضغط Commit.

### 4) حط المفتاح كسر
1. من المستودع: **Settings ← Secrets and variables ← Actions ← New repository secret**.
2. الاسم: `TELEGRAM_BOT_TOKEN`
3. القيمة: المفتاح اللي نسخته من BotFather. اضغط Add secret.

### 5) جرّب
1. افتح تبويب **Actions**. لو ظهرت رسالة تطلب تفعيل الـ workflows اضغط Enable.
2. اختار **Quran daily reminder ← Run workflow**، سيب الاختيار `test-send`، واضغط Run workflow.
3. بعد دقيقة المفروض توصل رسالة ورد اليوم في الجروب. التشغيل ده بيكتشف الجروب لوحده ويحفظه.

خلاص. من هنا الرسالة بتتبعت كل يوم لوحدها.

## تغيير الوقت أو الخطة
افتح `config.json` في GitHub (أيقونة القلم) وغيّر القيمة واحفظ:

| الحقل | معناه |
|---|---|
| `send_time` | وقت الإرسال بتوقيت القاهرة، مثلاً `"06:00"` |
| `start_date` | تاريخ أول يوم، مثلاً `"2026-11-10"` |
| `from_surah` / `to_surah` | رقم سورة البداية والنهاية (1 إلى 114) |
| `pages_per_day` | عدد الصفحات اليومي |
| `rest_weekday` | يوم راحة أسبوعي مثل `"friday"`، أو `null` لو مفيش |
| `group_name` | اسم الجروب، بيفيد لو البوت في أكتر من جروب |

أسهل طريقة: غيّر الخطة في أداة "ورد المراجعة"، وانسخ `config.json` من قسم التنبيه، والصقه مكان القديم.

## ملاحظات مهمة
- **التأخير:** GitHub بيشغّل الجدولة كل 15 دقيقة تقريبًا، فالرسالة بتوصل بعد وقتك بحد أقصى 15 إلى 30 دقيقة. ده من طبيعة GitHub، ومفيش طريقة مجانية أدق منه.
- **ليه Public؟** الجدولة كل 15 دقيقة بتستهلك دقائق Actions. في المستودعات العامة الدقائق مجانية بلا حد. المفتاح محفوظ في Secrets ومش ظاهر لأي حد. لو عايزه Private، افتح `remind.yml` وغيّر سطر `cron` لـ `"3,33 * * * *"` عشان تفضل في الحصة المجانية.
- **لو الجدولة وقفت:** GitHub ممكن يوقف الجدولة في المستودعات اللي مفيهاش نشاط 60 يوم. الحفظ اليومي لملف `state.json` غالبًا بيمنع ده، ولو حصل افتح تبويب Actions واضغط Enable.
- **منع التكرار:** `state.json` بيسجل آخر يوم اتبعت فيه، فمفيش رسالة بتتكرر في نفس اليوم.
- **لو الجروب اتحوّل لسوبر جروب:** السكريبت بيلتقط ده تلقائيًا.
- **لو عايز توقف التنبيه:** من تبويب Actions اختار الـ workflow ثم القائمة (...) ثم Disable workflow.
- **أمان المفتاح:** متكتبوش في أي ملف ولا في أي محادثة. لو اتسرّب، ارجع لـ BotFather واعمل `/revoke` وخد مفتاح جديد.

## تجربة على جهازك (اختياري)
```
python quran_reminder.py --dry-run          # يطبع رسالة اليوم
python quran_reminder.py --dry-run --day 5  # يطبع رسالة اليوم رقم 5
```
